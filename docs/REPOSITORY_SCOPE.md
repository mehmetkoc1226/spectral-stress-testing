# Repository scope

This is a code-only reproducibility repository.

Included:

- audited Stage 1 and Stage 2 experiment code;
- English-only Colab notebooks;
- exact model and intervention registries;
- successful full-run configurations and recorded environments;
- exact dataset and calibration-split manifests;
- run and phase completion evidence;
- fitted calibration parameters;
- compact aggregate and bootstrap analyses;
- reproducibility, provenance, unit tests, and continuous integration.

Excluded:

- manuscript source and compiled article files;
- manuscript figure directories and submission records;
- dataset images and pretrained weights;
- per-image prediction chunks;
- selected and full logits;
- credentials, private Drive links, caches, and temporary files.
